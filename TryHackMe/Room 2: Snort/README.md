# Snort

**Type:** Walkthrough / Practical
**Focus:** IDS/IPS, Network Traffic Analysis, Snort Rules

## Tools Used

* Snort
* Linux
* PCAP files

## What I Did

* Learned the difference between IDS and IPS.
* Explored Snort as a network intrusion detection and prevention tool.
* Used Snort in **Sniffer Mode** to inspect network traffic.
* Used **Packet Logger Mode** to capture and analyse network traffic.
* Analysed captured traffic and PCAP files.
* Learned how Snort detects suspicious activity using rules.
* Practiced creating and understanding basic Snort rules.
* Investigated network traffic and identified potential threats.

## Key Learnings

* Difference between NIDS, NIPS, HIDS and HIPS.
* How Snort can monitor and analyse network traffic.
* How packet logging can be used for traffic investigation.
* How Snort rules are structured.
* Difference between signature-based and behaviour-based detection.
* How IDS/IPS tools can be used to detect and respond to suspicious network activity.

## Takeaway

This room gave me practical experience with Snort and helped me understand how network traffic can be monitored, logged and analysed to detect potential security threats.
