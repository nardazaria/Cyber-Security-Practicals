# Blue

**Type:** Walkthrough / Practical
**Focus:** Windows Security, SMB, MS17-010, Metasploit, Privilege Escalation

## Tools Used

* Nmap
* Metasploit
* John the Ripper
* Meterpreter
* Windows command line

## What I Did

* Scanned the target using Nmap and identified open ports and services.
* Identified the Windows SMB vulnerability (MS17-010).
* Used Metasploit to exploit the vulnerability and gain initial access.
* Converted the shell to a Meterpreter session.
* Escalated privileges to `NT AUTHORITY\SYSTEM`.
* Enumerated running processes and practiced process migration.
* Dumped password hashes and practiced password cracking.
* Located files and sensitive information on the compromised Windows machine.

## Key Learnings

* How to perform basic network and service enumeration.
* How SMB vulnerabilities can be identified through scanning.
* How Metasploit can be used during a penetration test.
* Understanding the difference between an initial shell and a Meterpreter session.
* Practicing privilege escalation on Windows.
* Understanding the importance of protecting credentials and sensitive files.

## Takeaway

This room gave me practical experience with Windows enumeration, SMB vulnerability exploitation, Metasploit, privilege escalation, and credential security in a controlled environment.
