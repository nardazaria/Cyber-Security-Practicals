# Room: h4cked

**Type:** Challenge
**Focus:** PCAP Analysis, FTP, Web Shell, Privilege Escalation

## Tools Used

* Wireshark
* Hydra
* FTP
* Netcat

## What I Did

* Analysed a `.pcap` file using Wireshark.
* Identified FTP traffic and investigated the attacker's login attempts.
* Used the captured traffic to understand how the attacker gained access.
* Investigated the uploaded web shell and how it was used to obtain a reverse shell.
* Reproduced the attack in the TryHackMe lab environment.
* Practiced privilege escalation to obtain root access.

## Key Learnings

* Analysing network traffic with Wireshark.
* Identifying brute-force activity in packet captures.
* Understanding how FTP can be abused when weak credentials are used.
* Understanding how a web shell can lead to a reverse shell.
* Practicing privilege escalation in a controlled environment.

## Takeaway

This room helped me understand how to analyse an attack from network traffic and then reproduce the attack in a controlled lab environment.
